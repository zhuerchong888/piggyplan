PiggyPlan 1.1.1 Windows 绿色便携版
============================

启动方式
--------
双击 PiggyPlan.exe 即可运行，无需安装 Python、浏览器或数据库软件。

请保留 PiggyPlan.exe 与 _internal 文件夹的相对位置，不要只移动 EXE。
如需移动软件，请整体移动 PiggyPlan 文件夹。

本地数据
--------
数据库：%APPDATA%\PiggyPlan\piggyplan.db
每日备份：%APPDATA%\PiggyPlan\backups
技术日志：%APPDATA%\PiggyPlan\logs

软件不要求账号，核心功能不需要网络，任务内容不会默认上传。

界面与快捷操作
--------------
全应用统一使用小猪粉。Ctrl + N 新建待办，Ctrl + F 搜索。
新建待办只显示核心字段，需要补充备注、优先级、标签或子步骤时点击“更多选项”。
分类统一为“工作 / 学习”，已有“生活”分类记录自动显示为“学习”。
默认 Ctrl + Alt + T 全局快速添加。若快捷键冲突，可在设置页修改。
表单可滚动，Tab 可切换字段，保存/取消按钮始终位于弹窗底部。
从设置页导出完整备份，恢复前会保留当前数据快照。

退出软件
--------
默认点击窗口关闭按钮会隐藏到系统托盘。需要完全退出时，右键托盘图标并选择“退出”。
